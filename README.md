# DentariaSys - Sistema de Gestión Odontológica

**DentariaSys** es un sistema web diseñado para simplificar y modernizar la administración de historias clínicas y la gestión de pacientes en centros odontológicos. El proyecto busca ofrecer una herramienta intuitiva, segura y eficiente para los profesionales de la salud dental.

## Características Actuales

* **Autenticación Segura**: Sistema de registro e inicio de sesión para el personal autorizado.
* **Gestión de Pacientes (CRUD)**: Funcionalidad completa para crear, leer, actualizar y desactivar perfiles de pacientes.
* **Filtrado y Búsqueda**: Búsqueda dinámica de pacientes y filtrado por estado (activos/inactivos).
* **Base de Datos Relacional**: Estructura de datos sólida que vincula a cada paciente con su futura historia clínica.

## Tecnologías Utilizadas

* **Backend**: PHP 8+ / **Laravel 11**
* **Frontend**: Plantillas **Blade** con **Tailwind CSS**
* **Base de Datos**: **PostgreSQL**
* **Entorno de Desarrollo**: **Docker** y Docker Compose
